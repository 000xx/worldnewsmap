# 🌍 World News Map

A free, ad-free, open-source interactive map showing what's happening around the world — especially in places mainstream media undercovers.

## How It Works

**Data flows through a simple pipeline:**

1. **GDELT** (Global Database of Events, Language, and Tone) provides real-time global event data — geocoded, categorized, and scored for intensity
2. **Google News RSS** and **The Guardian API** supplement with readable article headlines
3. A **Python script** runs every 30 minutes via GitHub Actions, processing and merging the data
4. The **frontend** (a single HTML file) fetches the resulting JSON and renders it on a Leaflet map

## Features

- **Category filtering** — toggle between Conflict, Politics, Economy, Environment, Humanitarian, Health, and Positive News views
- **Intensity sizing** — bubble size reflects a composite of source count, impact severity (Goldstein Scale), and emotional tone
- **5+ source threshold** — only events corroborated by multiple independent sources appear, filtering noise and misinformation
- **Click for details** — each hotspot shows source count, intensity score, tone, and links to original articles
- **Zero cost** — runs entirely on free services (GitHub Pages, GitHub Actions, GDELT, RSS)

## Quick Start

### View the map locally
Just open `index.html` in your browser. It loads with demo data showing 15 global hotspots.

### Run the pipeline locally
```bash
cd pipeline
python orchestrator.py
```
This fetches live GDELT data and writes `data/live.json`.

### Connect frontend to live data
In `index.html`, change the config:
```javascript
const CONFIG = {
  dataURL: './data/live.json',  // ← point to your JSON file
  ...
};
```

### Deploy
1. Push to GitHub
2. Enable GitHub Pages (Settings → Pages → Source: main branch)
3. The GitHub Action will auto-update `data/live.json` every 30 minutes

## Optional: Guardian API Key

Get a free key from [The Guardian Open Platform](https://open-platform.theguardian.com/).
Add it as a GitHub repository secret named `GUARDIAN_API_KEY`.
